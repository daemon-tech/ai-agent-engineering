# Finding external human reviewers

Keep it simple:

1. Open a pinned issue "Looking for reviewers" with one chapter per checkbox and a 1-hour scope.
2. Ask 3–5 people directly: authors of papers we cite (they know the claims best) and practitioners who build agents.
3. Ask for one thing: check the claims and evidence tags in one chapter. Review via GitHub issue or PR comment.
4. Credit reviewers by name in the README (opt-in).
5. Announce each release (v0.1.1, ...) with a call for review.
