# Annotated paper entries

Each entry follows the same template so entries can be compared:

1. **Bibliographic record**: title, authors, date, venue, DOI/URL, BibTeX key, evidence class, and the record used for verification.
2. **Research question**
3. **Method**
4. **Key findings**, as numbers with setup, quoted from the primary source
5. **Setup and benchmark limitations**
6. **Novelty**, as claimed by the authors and as assessed by us **[OP]**
7. **Connections** to other entries
8. **Open questions**
9. **Implications for AAE** **[OP]**
